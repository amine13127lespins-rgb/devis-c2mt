🧠 Cerveau IA (Claude API)

Sans clé, le chat comprend des ordres simples. Avec une clé API Anthropic, le chat devient une vraie conversation avec Claude : il comprend tout, discute de tout, et commande les personnages tout seul.

Pour avoir une clé : crée un compte sur console.anthropic.com, ajoute un petit crédit (quelques euros suffisent pour des centaines de messages), puis crée une clé API et colle-la ici. La clé reste enregistrée uniquement sur ton téléphone.

⚠️ Important : sur ce lien claude.ai, les connexions vers l'extérieur sont bloquées — le cerveau IA ne marchera que sur la version hébergée sur ton site GitHub Pages.

➕ Inviter un agent

Une nouvelle pièce s'ajoute pour chaque agent. Les agents ne font rien d'eux-mêmes : ils obéissent uniquement à tes ordres dans le chat et aux directives programmées ci-dessus. Chaque rapport déposé est partagé dans la boîte aux lettres commune. Pour ChatGPT et Meta Ads, la vraie connexion API pourra être branchée plus tard — en attendant l'agent travaille en simulation.
